# Abby Bond — Marketing Portfolio

Portfolio website for Sarah “Abby” Bond, BBA Marketing, UTSA 2026.

## Adding portfolio work

The site intentionally includes placeholders for internship and school projects. Replace the placeholder blocks in `index.html` with images, videos, project descriptions, and verified results as they become available.

Recommended folders:
- `assets/images/` — campaign graphics, screenshots, project covers
- `assets/videos/` — small web-optimized videos
- `assets/docs/` — portfolio PDFs or presentations

For large videos, embed a hosted video rather than committing very large media files directly to the repository.

## GitHub Pages

Publish from the repository's `main` branch in GitHub Pages settings.
